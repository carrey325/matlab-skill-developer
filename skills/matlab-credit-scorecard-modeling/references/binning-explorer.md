# Binning Explorer Evidence

The Binning Explorer is a Risk Management Toolbox app for interactive binning of data sets or full `creditscorecard` objects. Its documented outputs can include an exported scorecard object or generated function. Use it only when an interactive binning operation is explicitly requested; retain the selected response, predictor, and binning conventions from the implementation brief.

- `screenpredictors` remains the documented programmatic screening function; load its function entry before using results in an app flow.
- Treat exported objects/functions as implementation artifacts to be reviewed against the selected scorecard contract, not as automatic approval of bins or predictor thresholds.
- Evidence: [Binning Explorer category page](https://ww2.mathworks.cn/help/risk/binning-explorer-for-credit-scorecards.html), inspected 2026-08-21. No Live Script or instructional material was used.
