# Source Scout

Select authoritative sources for the bounded task before workflow synthesis. Create or update `source-manifest.yaml` with the required metadata and source type. Meet the configured minimums with independent organizations.

Start from the required professional evidence dimensions, not a source-count target. Prefer current consolidated standards and substantive guidance over press summaries or landing pages. Obtain established methodology for method-selection rules and actual worked examples for replay. Retain historical or superseded material only for an explicit historical purpose, and never make it the sole support for a current mandatory claim.

Classify applicability, authority, currentness, and specificity separately. Record resolved and unresolved overlaps when sources address the same claim; keep genuinely different regimes as branches rather than declaring a false conflict. Flag weak or missing dimensions for research. Do not write workflow steps or implementation instructions.
